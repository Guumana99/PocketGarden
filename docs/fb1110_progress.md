- **13 アプリの大きさ（調べただけ。直していない）**
  - デバッグ APK 80.4MB（11/10 夜）の中身：ネイティブライブラリ 19.5MB（4 種の CPU 向け。SQLCipher が 1 つ 3.6〜5.7MB）、絵のアトラス 18.6MB、コード 17.7MB（デバッグは縮めていない）、res の画像 11.8MB、BGM 10.3MB、効果音 0.3MB、その他 1.1MB。
  - リリース（AAB、R8 で縮める）ではコードは約 3MB、ライブラリは 1 種の CPU あたり約 2.3MB。Play で 1 台に届く量の目安：絵 30MB＋BGM 10.6MB＋コード約 3.5MB＋ライブラリ約 2.3MB＋その他約 1MB ≒ **47MB 前後**（デバッグ APK の 80MB よりずっと小さい）。
  - 減らす案：(1) PNG をロスレス WebP に：絵 29.5 → 20.7MB（−8.8MB、見た目は変わらない）。(2) 画質 90 の WebP：→ 7.6MB（−22MB、縁や細部がわずかに変わる。要確認）。(3) アトラスの解像度を下げる（1 マス 512 → 384 px で約 −7MB、最大まで寄ったときに少しぼやける）。(4) BGM の品質 5 → 3：約 −3MB（音が少し変わる）。(5) 効果音の形式：0.3MB しかないので効果は小さい。(6) AAB で配る（今の AAB のままで、CPU 別・画面密度別に分かれて届く。上の 47MB はこれを入れた目安）。
