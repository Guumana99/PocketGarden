### 2. ことりが `land_on` でコテージのマスを指したとき、屋根に降りるか

**降りない（地面に降りる）。** 撮影ではことりを `host = null`・`cell = land_on` で呼ぶので、`CreatureRoutes.plan` は地面を歩く道筋（`planOnGround`）になり、コテージのマスの地面に降りる。
ゲームでは、ことりがコテージ目当てに来たとき（`host` がコテージ）に `planOnHost` で屋根の棟（`CreaturePerches`：コテージの左上から (1.4, 1.5)・(2.0, 1.5)、高さ 1.83 タイル幅）に止まる。
→ ⑤ で、撮影側（`ScenarioPlayer`）だけを直す：ことりの `land_on` のマスに屋根のある建物（コテージ・小屋）があれば、その建物を `host` にして呼ぶ。ゲームの動きは変えない。

### 3. `place` でコテージを置いたとき、建てる時間・工事の絵が出るか

**出ない。** 撮影の `place` は `GridObject` を `workKind = NONE`（工事なし）で作るので、置いた瞬間から建った姿。直す必要なし。
